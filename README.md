# Sistema de Jogadores em Java

Exercício acadêmico em Java para praticar fundamentos de programação orientada a objetos.

## Objetivo

O programa cria uma coleção de jogadores, registra pontos para cada um e apresenta o placar no terminal.

## Conceitos praticados

- Classes e objetos
- Atributos e métodos
- Arrays de objetos
- Laços `for`
- Variáveis de instância e de referência

## Estrutura

```text
src/
├── Jogador.java      # Entidade e comportamento de um jogador
└── TestJogador.java  # Ponto de entrada e demonstração do placar
```

## Como executar

### Pelo NetBeans

1. Abra o projeto no NetBeans.
2. Execute a classe `TestJogador.java`.

### Pelo terminal

Com um JDK instalado, na raiz do repositório execute:

```bash
javac -d out src/*.java
java -cp out TestJogador
```
